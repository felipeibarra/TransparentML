================================================================================
                        FLUJO DE DATOS DETALLADO
================================================================================

1. CARGA DE DATOS (data_loader.py)
   ┌─────────────────────────────────────────────────────────┐
   │ Input:  kddcup.data_10_percent                          │
   │ Output: DataFrame con 494,021 filas x 41 columnas      │
   │ Acción: Parseo CSV, asignación de nombres de columnas  │
   └─────────────────────────────────────────────────────────┘

2. PREPROCESAMIENTO (preprocessing.py)
   ┌─────────────────────────────────────────────────────────┐
   │ a) Limpieza:                                            │
   │    - Eliminación de duplicados                          │
   │    - Manejo de valores nulos (mediana/moda)            │
   │                                                         │
   │ b) Encoding:                                            │
   │    - Label Encoding para variables categóricas          │
   │    - Variables: protocol_type, service, flag, label     │
   │                                                         │
   │ c) Scaling:                                             │
   │    - StandardScaler para normalización                  │
   │    - Fit en train, transform en test                    │
   │                                                         │
   │ d) Split:                                               │
   │    - Train: 70% (~345,815 muestras)                    │
   │    - Validation: 10% (~49,402 muestras)                │
   │    - Test: 20% (~98,804 muestras)                      │
   └─────────────────────────────────────────────────────────┘

3. MODELADO (models.py)
   ┌─────────────────────────────────────────────────────────┐
   │ Para cada modelo:                                       │
   │   1. Inicialización con hiperparámetros                │
   │   2. Entrenamiento con X_train, y_train                │
   │   3. Predicción en X_test                              │
   │   4. Serialización del modelo (.joblib)                │
   │                                                         │
   │ Modelos implementados:                                  │
   │   - Linear Regression: β = (X'X)⁻¹X'y                  │
   │   - Ridge: β = (X'X + λI)⁻¹X'y                         │
   │   - Lasso: min(||y-Xβ||² + λ||β||₁)                   │
   │   - ElasticNet: min(||y-Xβ||² + λ₁||β||₁ + λ₂||β||²)  │
   │   - Polynomial: X → [X, X², X³, ...]                   │
   └─────────────────────────────────────────────────────────┘

4. EVALUACIÓN (evaluation.py)
   ┌─────────────────────────────────────────────────────────┐
   │ Métricas calculadas:                                    │
   │   MAE  = (1/n) Σ|yᵢ - ŷᵢ|                             │
   │   MSE  = (1/n) Σ(yᵢ - ŷᵢ)²                            │
   │   RMSE = √MSE                                           │
   │   R²   = 1 - (SS_res / SS_tot)                         │
   │                                                         │
   │ Validación:                                             │
   │   - 5-Fold Cross Validation                            │
   │   - Análisis de residuos (normalidad, homocedasticidad)│
   │   - Comparación entre modelos                          │
   └─────────────────────────────────────────────────────────┘
