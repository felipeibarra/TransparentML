 1. SYSTEM OVERVIEW
═══════════════════════════════════════════════════════════════════════════════

TransparentML is an enterprise-grade machine learning platform built from
scratch using NumPy. It provides multiple ML algorithms exposed as REST APIs
with a centralized dashboard for analysis and visualization.

**Core Principles:**
  • Pure NumPy implementations (no sklearn for core algorithms)
  • Microservices architecture
  • RESTful APIs
  • Real-time analysis
  • Educational focus with enterprise quality

 10. INTEGRATION PATTERNS
═══════════════════════════════════════════════════════════════════════════════

10.1 SERVICE-TO-SERVICE COMMUNICATION
──────────────────────────────────────
Pattern: REST over HTTP
Protocol: JSON
Network: Docker bridge network (transparentml-network)

Example:
  Dashboard → http://linear-regression:8001/api/v1/train


10.2 REAL-TIME UPDATES
──────────────────────
Pattern: Server-Sent Events (SSE)
Use Case: Streaming logs during analysis

Example:
  Dashboard ← EventSource("/api/v1/logs/{id}")
           ← data: {"log": "Processing...", "timestamp": "..."}


10.3 AI CHATBOT INTEGRATION
────────────────────────────
Pattern: Context-Aware API Calls
Provider: Groq (free tier)
Model: llama3-8b-8192 or mixtral-8x7b-32768

Flow:
  1. User asks question
  2. Dashboard collects ML results context
  3. POST to Groq API with context
  4. Stream response to user


10.4 ERROR HANDLING
───────────────────
Pattern: Graceful Degradation
- Service down → Show error message
- Timeout → Retry with exponential backoff
- Invalid input → Validation errors
- Network error → Offline mode
