## 🎯 What is TransparentML?

<div align="center">

```ascii
╭───────────────────────────────────────────────────────────────╮
│  "We believe ML should be explainable, auditable, and         │
│   trustworthy. No black boxes. No hidden magic.              │
│   Just pure mathematics you can understand and verify."       │
╰───────────────────────────────────────────────────────────────╯
```

</div>

**TransparentML** is an enterprise-grade machine learning platform where every algorithm is implemented from scratch using only NumPy. Perfect for organizations that need explainable AI, educational institutions teaching ML fundamentals, or developers who want complete control over their models.

<br>

<details>
<summary><b>🌟 Key Features (click to expand)</b></summary>
<br>

| Feature | Description |
|---------|-------------|
| 🔓 **Zero Black Boxes** | Every line of code is visible and auditable. No hidden transformations. |
| 🎓 **NumPy Only** | Core algorithms use only NumPy - no scikit-learn for ML logic |
| 🐳 **Docker Native** | Multi-service architecture with one-command deployment |
| 🌐 **REST APIs** | Production-ready FastAPI endpoints for each algorithm |
| 📊 **Full Observability** | Health checks, logging, metrics, and monitoring built-in |
| 📖 **Rich Documentation** | ASCII diagrams, mathematical explanations, and examples |
| 🧪 **Test Coverage** | Comprehensive unit and integration testing |
| ⚡ **Make Automation** | 40+ commands for building, testing, and deploying |
| 🔐 **Enterprise Security** | Network isolation, read-only mounts, health monitoring |
| 📈 **Horizontally Scalable** | Each service can scale independently |

</details>

## 🎓 Educational Philosophy

### Why Implement From Scratch?

1. **Deep Understanding**: Implementing algorithms reveals mathematical foundations
2. **No Black Boxes**: Every computation is explicit and traceable
3. **Debugging Skills**: Learn to diagnose and fix algorithmic issues
4. **Interview Prep**: Demonstrate mastery beyond library usage
5. **Research Ready**: Foundation for algorithm modifications

### Learning Path

1. **Study Theory**: Read notebooks with mathematical explanations
2. **Explore Code**: Examine step-by-step implementations
3. **Run Examples**: Execute notebooks with sample data
4. **Modify & Experiment**: Change parameters, observe effects
5. **Apply**: Use APIs with your own datasets

## 🔌 API Reference

### Linear Regression API

```bash
# Train model (if needed)
POST /api/v1/linear-regression/train
Content-Type: application/json

# Predict
POST /api/v1/linear-regression/predict
Content-Type: application/json
{
  "features": [[1.2, 3.4, 5.6, ...]]
}

# Get metrics
GET /api/v1/linear-regression/metrics
```

### PCA API

```bash
# Fit PCA (if needed)
POST /api/v1/pca/fit
Content-Type: application/json
{
  "n_components": 2
}

# Transform data
POST /api/v1/pca/transform
Content-Type: application/json
{
  "data": [[5.1, 3.5, 1.4, 0.2]]
}

# Get explained variance
GET /api/v1/pca/explained-variance
```
